## 2. 最終版本預計完成項目

- 錢包

  - 使用者可以把一群人加入某個錢包（依照 userId）。
  - 使用者在首頁可以選擇本人 / 全部人，顯示當日的所有款項與該月的支出 / 收入。
  - 使用者在明細頁面可以選擇本人 / 全部人顯示每月的所有款項，並額外標註付款者與自己的分帳金額，與各種標籤的支出比例。
- 記帳

  - 使用者在改變幣別時，可以設定與 NTD 的匯率。當次匯率以「上一次使用之匯率」為預設，「手動輸入」作為 Fallback，與「當日匯率」作為可選項。
- 記帳（分帳）

  - 使用者在新增款項時，可以設定付款（預設使用者）。
  - 使用者在新增款項時，可以設定分帳者（預設平均分帳）。
  - 使用者可以新增詳細的付款人與金額。
  - 使用者可以新增詳細的分帳人與金額。
  - 使用者可以看到該群組目前的結餘狀態。
  - 使用者可以得到最方便的還錢方法。
- 訂閱（假設週期是月，使用者可以自己調整）

  - 使用者可以在訂閱頁面 CRUD 一筆訂閱項目，在每月的該日自動新增該筆款項。
- 通知

  - 當訂閱費要扣款前 2 天給予通知。
  - 使用者可以已讀通知。
  - 當有人還你錢了，通知欄會多一則通知。
- 載具

  - 使用者所刷過的載具每半天會被引入 app 中，並自動設定標籤（餐飲、交通等）列在明細中。
- 視覺化圖表

  - 使用者可以在明細頁面，根據不同錢包、不同標籤，或是年月日去做篩選與組合獲得圖表。
  - 每月的收支圓餅圖表，與各種標籤的支出比例
  - 不同月的支出可以用長條圖呈現。
- 接到 LINE
- 把 web 變成 app
- 消費建議 AI
- 引入消費紀錄，來源包括（但不限於） LINE Pay 消費通知、信用卡刷卡簡訊 / 推播、E-mail 收據等。只需授權來源（例如：Android 通知存取、Gmail 解析、LINE Notify 轉送）即可自動記帳，並提供錯誤校正、分類建議與每月報表，降低記帳摩擦。
