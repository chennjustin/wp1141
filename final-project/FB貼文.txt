[這個服務在做什麼]：Coin Undergraduate 是一款多人協作的記帳與分帳系統，支援多錢包管理、自動分帳計算、訂閱服務自動記帳等功能。使用者可以建立多個獨立錢包，例如個人日常開銷、投資理財、或是與朋友共同出遊的費用分攤。系統支援多幣別記帳，自動記錄匯率，並提供完整的標籤分類功能。最特別的是自動化的訂閱管理功能，系統會自動在每個週期到期時建立交易記錄，並在扣款前兩天發送提醒通知。分帳功能讓多人協作變得簡單，系統會自動計算每個成員的結餘狀態，並提供最優化的還款建議，幫助使用者快速了解誰該還誰多少錢。

[使用/操作方式] 使用者端：

一開始先透過 Google OAuth 登入系統，登入後會看到錢包列表頁面。系統預設會有一個「我的錢包」，使用者也可以建立新的錢包，每個錢包可以設定名稱、預設幣別、描述等資訊。在錢包列表頁面，使用者可以將常用錢包釘選到首頁，最多可以釘選 3 個錢包，系統會記住使用者上次選擇的錢包作為預設錢包。

進入錢包後，可以在首頁查看當日所有交易與當月收支總覽。點擊「新增交易」按鈕，可以選擇交易類型（收入或支出）、標籤、輸入金額、日期、幣別、名稱與備註。當交易使用非預設幣別時，系統會記錄匯率，可以選擇使用上次匯率或手動輸入。如果錢包有多個成員，可以設定「誰先付錢」和「如何分」，支援平均分攤或自訂金額分攤。系統會自動計算每個成員的結餘狀態，並在首頁顯示還款建議。

在歷史明細頁面可以查看所有交易記錄，支援標籤篩選功能，方便快速分類與查詢。每筆交易都可以進行編輯或刪除操作。

訂閱管理功能讓使用者可以建立訂閱項目，設定金額、幣別、週期（每日、每週、每月、每年或自訂）、開始日期與結束日期。如果訂閱的開始日期在過去，系統會自動補齊從開始日期到今天的交易記錄。訂閱項目同樣支援分帳功能，可以設定付款人與分帳人，方便管理像是 Netflix、Spotify 等多人共享的訂閱服務。系統會透過 Vercel Cron Jobs 每日自動檢查到期訂閱並建立交易記錄，無需使用者手動操作。

通知系統會在訂閱費用即將扣款前兩天發送提醒通知，當有成員還款時，相關使用者也會收到通知。通知支援已讀標記，使用者可以在通知頁面查看所有未讀與已讀通知。系統使用 Pusher 提供即時推送通知功能。

標籤系統提供預設的支出與收入標籤，例如「飲食」、「飲料」、「旅遊」等支出標籤，以及「薪水」、「投資」等收入標籤。使用者也可以建立自訂標籤，每個標籤可以設定圖示方便視覺化識別。

系統提供完整的 Swagger/OpenAPI API 文件，可以在 `/api-docs` 頁面查看互動式 API 文件，並支援直接在瀏覽器中測試 API 的功能。

[使用與參考之框架/模組/原始碼]

前後端：Next.js 14 (App Router) + TypeScript

資料庫：Prisma ORM + PostgreSQL

佈署：Vercel (包含 Vercel Cron Jobs)

即時通訊：Pusher

登入：NextAuth.js v4 (Google OAuth)

樣式：Tailwind CSS

圖示：Lucide React

圖表：Recharts

資料驗證：Zod

測試：Vitest (單元測試) + Playwright (E2E 測試)

API 文件：Swagger/OpenAPI

[使用之第三方套件、框架、程式碼]

主要第三方套件包含：Next.js、React、TypeScript、NextAuth.js、Prisma、PostgreSQL、Tailwind CSS、Pusher、Zod、Lucide React、Recharts、Vitest、Playwright、Swagger UI 等。
